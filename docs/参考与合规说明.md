# 参考与合规说明

moon-miniprogram 是原创项目，不是已有框架的语言移植。核心的 MoonBit 运行时、状态
diff、页面与组件装配、store、路由、wx 绑定、脚手架和无头模拟器均在本仓库独立实现，
以 Apache-2.0 许可证发布。

设计与兼容性调研参考以下开源项目：

| 项目 | 来源 | 许可证 | 本项目的参考范围 |
|---|---|---|---|
| Mpx | [didi/mpx](https://github.com/didi/mpx) | Apache-2.0 | 小程序框架的工程结构、页面与组件开发体验 |
| 微信小程序 API 类型定义 | [wechat-miniprogram/api-typings](https://github.com/wechat-miniprogram/api-typings) | MIT | 微信公开 API 的名称、参数与返回结构核对 |
| miniprogram-simulate | [wechat-miniprogram/miniprogram-simulate](https://github.com/wechat-miniprogram/miniprogram-simulate) | MIT | 无头组件测试能力边界的对照 |

仓库未复制上述项目源码，也未把其代码或资源打包进发布产物。相似的 App、Page、
Component 和 `setData` 名称来自微信小程序平台公开接口；本项目用 MoonBit 类型、FFI
边界和自有运行时重新实现。发布包没有运行时第三方 npm 依赖，MoonBit 依赖仅为官方
core JSON 包。若后续引入第三方源码或资源，将在对应文件和本说明中保留来源与许可证。
