# 参赛作品说明：moon-miniprogram（兔小程序）

MoonBit 9 月黑客松，新项目方向。仓库：
[Magic486/moon-miniprogram](https://github.com/Magic486/moon-miniprogram)；发布包：
`Magic486/moon-miniprogram@0.5.3`。

项目为 MoonBit 微信小程序开发框架。开发者用 MoonBit 定义 App、页面、组件、状态、
路由和事件，编译为一个 CommonJS 引擎；WXML/WXSS 保持微信原生，小程序 JS 入口只负责
装配。它服务于商城、工具、内容社区等多页面项目，也可作为现有小程序逐页迁移的运行时。

核心能力包括：类型安全的页面与组件模型、`set_state` 自动最小路径 diff、跨页响应式
store、参数白名单路由、常用 wx API 绑定、生命周期自动清理、错误边界、零依赖 CLI、
脚手架和可复用的微信运行时模拟器。1000 项列表追加一项时，基准快照中的序列化 JSON
字符数由 34,959 降至 49；数据为确定性测试指标，不宣称等同于网络字节数。

仓库包含 54 项 MoonBit 测试和 40 项端到端冒烟断言。CI 同时验证框架源码、实际交付
产物，以及从 Mooncakes 安装依赖的新项目脚手架。评委可执行：

```bash
moon check
moon test
powershell scripts/build-example.ps1
```

随后在微信开发者工具中导入仓库根目录，即可体验计数、跨页购物车状态、自定义组件
事件、路由、复制与分享。完整步骤见[验收指南](../验收指南.md)，原创与开源参考边界见
[参考与合规说明](../参考与合规说明.md)。
